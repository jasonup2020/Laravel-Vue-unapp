# make:module 代码生成器使用说明

> 一键生成 C 端（只读）+ 管理端（CRUD）完整模块骨架，遵循 `SHARED_CONVENTIONS.md` 第 12、13 节。

---

## 0. 完整双语帮助 / Full bilingual help

```powershell
& "D:\BtSoft\php\83\php.exe" artisan make:module --show-full-help
```

输出包含：命令用途（英文/中文）、USAGE、全部参数与选项（含默认值、是否必填）、使用示例。
帮助内容从命令 `$signature` 动态生成，新增参数自动跟随。
也可用 Laravel 自带的 `-h` / `--help` 查看简述。

## 1. 命令

```powershell
# 进入后端目录
cd D:\wwwroot\ju_test02\laravel13-api-skeleton\backend-laravel13

# 基本用法（生成 C 端只读 + 管理端 CRUD，默认开启）
& "D:\BtSoft\php\83\php.exe" artisan make:module Notices

# 不带管理端（仅 C 端只读）
& "D:\BtSoft\php\83\php.exe" artisan make:module Notices --no-with-admin

# 带软删除字段
& "D:\BtSoft\php\83\php.exe" artisan make:module Notices --soft-deletes
```

### 参数

| 参数 | 说明 |
|---|---|
| `name` | 必选，StudlyCase 模块名，如 `Notices`、`UserFavorite` |
| `--with-admin` | 是否生成管理端 CRUD。**默认开启**；传 `--no-with-admin` 关闭 |
| `--soft-deletes` | 是否在迁移中加 `softDeletes()`（`deleted_at` 列）。默认关闭 |

---

## 2. 命名约定

输入 `name` 为 StudlyCase，按下表派生全部命名：

| 输入 (Studly) | snake 单数 | snake 复数 | 表名 | 路由前缀 | lang 文件 | 权限码模块段 |
|---|---|---|---|---|---|---|
| `Notices` | `notice` | `notices` | `notices` | `/api/notices` | `notice.php` | `admin:notice:*` |
| `UserFavorite` | `user_favorite` | `user_favorites` | `user_favorites` | `/api/user-favorites` | `user_favorite.php` | `admin:user_favorite:*` |
| `Product` | `product` | `products` | `products` | `/api/products` | `product.php` | `admin:product:*` |

> - 表名 = snake 复数；路由 URI 使用 snake 复数（如 `/api/notices`）。
> - lang 文件名 = snake 单数；翻译 key 形如 `notice.success`、`notice.saved`。
> - 权限码 = `admin:{snake_singular}:{action}`，action ∈ `list/create/update/delete`。

## 4. 路由与权限码补充步骤

生成器自动向 `routes/api.php` **末尾**追加两段路由：

- C 端：`GET /api/{snake}`、`GET /api/{snake}/{snowId}`（只读，无鉴权中间件，按模块需要自行加 `auth:api`）。
- 管理端：`/api/admin/{snake}` 下 GET/POST/PUT/DELETE，挂 `auth:admin-api` + `admin.permission:admin:{module}:{action}` + `admin.operation.log` + `idempotency`。

**追加前检测**：若 `routes/api.php` 已存在 `// ===== Module: {Name} (generated by make:module) =====` 标记，则跳过追加，避免重复注册。

**生成后必须手工补充**：

1. 在 `database/seeders/PermissionSeeder.php` 中补权限码：
   ```php
   'admin:notice:list', 'admin:notice:create',
   'admin:notice:update', 'admin:notice:delete',
   ```
2. 在后台角色管理中给对应角色分配上述权限码。
3. 如需菜单入口，在 `MenuSeeder` 中补菜单项并绑定 `permission_code`。

## 5. 大表 / 高并发模块开发规范（契约 13.3）

生成的 Repository / Service 默认已内置以下能力，开发新模块时遵循：

1. **索引先行**：迁移中对所有 `where / join / order by` 列建索引，并用 `->comment('Index purpose/索引用途')` 标注。生成器模板已对 `status`、`created_at` 建索引；新增筛选字段必须同步加索引。
2. **分页上限钳制**：`page_size` 最大 100，`BaseRepository::paginate()` 自动钳制。浅分页用 `paginate()`；深分页（offset > 10000）改用 `keysetPaginate($cursor, $pageSize, 'snow_id')`，按 `snow_id < cursor` 倒序 LIMIT。
3. **缓存钩子**：Repository 提供 `cacheKey(): ?string`、`forgetCache()`、`remember($ttl, $callback)`。高频只读列表覆盖 `cacheKey()` 开启 cache-aside；写操作后自动 `forgetCache()`。禁止 `Redis::` 直连，一律走 `Cache` facade。
4. **批量写**：批量导入用 `insertMany(array $rows)`（`INSERT ... VALUES (...),(...)`），禁止循环单条 `create()`；大结果集遍历用 `chunkById()`。
5. **禁止 `Model::all()`**；列表一律分页；关联查询用 `with()` 预加载避免 N+1。
6. **对外不暴露自增 `id`**：路由参数一律用 `snow_id`，控制器 `where('snow_id', $snowId)` 解析；Model `$hidden` 已默认隐藏 `id`。
7. **多表写必须 `DB::transaction`**：Service 层已封装 `transaction(callable)`，异常自动转 `ApiException`。

## 7. 下一步提示（生成器结尾输出）

生成器运行结束后会打印：

1. 编辑迁移补充业务字段（默认仅 name/title/status/remark 模板）；
2. 在 `PermissionSeeder` 补权限码 `admin:{module}:*`；
3. 确认无误后执行 `php artisan migrate`；
4. 同步更新 `openapi/openapi.yaml` 与 Pest 用例。
