## 六、多语言专项：缺口与复测结论

### 6.1 已修复并复测通过（构建 Agent + 本 Agent 补充修复）

构建 Agent 已落地：菜单双语 title（`admin_menus.title_en` 真库 17/17、`my-tree` 返回 `{zh-CN,en}` 对象、前端 MenuItem 按 locale 取标题）、前端语言包补全 `common.*`/`ui.rate.*`/`ui.recycle.*`、后端新增 `lang/{zh-CN,en}/ui.php`（65 key，接口总 353 key 含 md5）、`syncLocale` 单例锁收敛 `/api/locale` 请求。

本 Agent 复测补充修复 4 项（浏览器实测发现）：

* **【多语言包浅合并 bug】后端 ui.\* 段覆盖掉前端完整兜底**：`src/i18n/index.js` 的 `applyItems()` 用 `{...existing, ...nested}` 浅合并，后端语言包（含部分 `ui.*`）会把兜底包完整的 `ui.*`（~100 key）整体替换，导致切英文后 `ui.home`/`ui.product.*`/`ui.recycle.*` 等丢失、全部回退中文。修复：改为深度合并 `deepMerge()`（后端同名叶子优先、保留兜底其余 key）。

* **【面包屑仍中文】面包屑取的是 router `meta.title`（纯中文字符串）**，不是菜单树双语对象。修复：`layout/index.vue` 按当前路由 path 在菜单树中查找，取双语 title（找不到再回退 meta.title）。复测：Home / Dashboard、Home / Rate Limit、Home / Recycle Bin 全部英文 ✅。

* **【Element Plus 组件文案不随语言切换】**：`app.use(ElementPlus, { locale })` 只在启动时固定一次，运行时切语言后分页等内置组件仍中文（如"共 3 条"）。修复：改为 `App.vue` 用 `<el-config-provider :locale>` 响应式绑定 i18n locale。复测：英文态分页显示 "Total 3" ✅，中文态"共 3 条"✅。

* **【zh 语言包中英混杂】**：zh-CN `ui.recycle.products` 等值为"商品 products"（后端 `lang/zh-CN/ui.php` 与前端 fallback 同步修正为纯中文"商品/普通用户/管理员/菜单/角色/消息/收藏"）。复测：中文态显示"商品"✅。

### 6.2 复测通过明细（英文态实测）

侧边栏 Dashboard/Users/Business·Products·Dictionary/System·Admins·Roles·Menus·Permissions/Messages/Audit·Operation Logs·IP Blacklist·Rate Limit/Favorites/Recycle Bin 全英文；工作台统计卡（Admins/Users/Products/Messages）+ System health 英文；限流规则页 Rate limits/New rule/Rule key/Max attempts/Window (seconds) 英文；回收站页 Recycle Bin/Resource type/Products/Batch restore/Snow ID/Name/Deleted at/Restore 英文；成功 toast 显示 Success；语言切换双向即时生效、"刷新语言包"重拉生效。
